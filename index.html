Speech

Off by default. Each reply has a speaker button to listen on demand; Astra Live always talks.

Uses your phone's speech engine (Google). Urdu → ur-PK, Roman Urdu → Indian-English voice, Hindi → hi-IN, Punjabi → pa-IN. Voice packs are free and then work without internet.

Paid xAI API (api.x.ai/v1/tts). English/Hindi are officially listed; Urdu uses auto-detect. Falls back to the phone voice if offline or on any error.

Keys are saved in local Settings only — never baked into the app.

Checking…

Piper is an offline neural voice that runs on this phone (via sherpa-onnx). It is not inside the APK — each voice is a one-time download. Every voice package includes espeak-ng-data, the phoneme dictionary the Piper models need to turn text into sounds; it is unpacked once and shared (it is not used as a voice). English and Hindi have female voices. Urdu: the only Piper Urdu voice is male and its pronunciation is basic (Urdu script only, no diacritics); Roman Urdu is read with the English voice. Punjabi and Arabic have no Piper voice and use the phone voice. Pitch has no effect on Piper. If a voice isn't downloaded, Astra uses the phone voice.

Runs a visible “Astra is active” notification (foreground service, microphone) so voice conversation can continue when you press Home or Back. Android limits apply: it can stop on some phones when the screen is locked or under battery optimisation, and it never records secretly — the notification stays while it is on.

💡 You chose Piper. For a more natural voice, switch TTS provider to Auto (and add your xAI key for Grok voice).

Models & API keys

Astra pehle Groq, phir Gemini, phir free Pollinations try karti hai. Keys sirf is phone par rehti hain — kabhi code ya chat mein nahi.

Groq — primary

Primary: Groq (Qwen 27B), Backup: Gemini

groq.com پر مفت اکاؤنٹ بنا کر API key یہاں ڈالیں

With a Groq key Astra answers with Groq first. If Groq is busy, rejects the key, times out (~20 s) or replies empty, the same message is re-sent automatically to your Gemini key below, and if that also fails, to free Pollinations. A small line under the reply says when this happened. Photos go to Gemini first when a Gemini key is set. No Groq key = everything works exactly as before.

OpenAI

api.openai.com/v1/responses (OpenAI's Responses API, as in their "Build a Personal AI Assistant" guide) with streaming, photos (image input), Astra tools and Luna web search; if /v1/responses is unavailable (404) or blocked, the same message is re-sent to /v1/chat/completions automatically (no web search there). Web search calls are billed per search by OpenAI. GPT-6 Luna: text + image in, text out, ≈ $0.10 in / $0.50 out per 1M tokens (developers.openai.com). Only used when a key is saved here; you can type any other OpenAI model id. If OpenAI rejects the key, has no credits (429 insufficient_quota) or is busy, Astra moves on to the next provider automatically. Billed by OpenAI to your account.

Grok (xAI)

OpenAI-compatible API at api.x.ai/v1 (docs.x.ai/docs/models: grok-4.3 ≈ $1.25 in / $2.50 out per 1M tokens, grok-4.7 is their top model). Not part of Astra's default chain — it is only used if you switch it on here. Billed by xAI to your account.

Gemini / other provider

Presets map to real models for the provider you choose.

When set, AI/TTS/image calls go through your Node proxy (env keys). Leave empty to use keys stored on this device.

Online / Offline mode

Offline: phone actions (call, message, alarms, timers, reminders, torch, apps, media, settings) run on the built-in rule engine, speech recognition prefers the on-device model, replies use the phone voice. Open questions need Online — or the optional on-device model below.

On-device AI (optional) · Android only

Checking…

Qwen2.5-0.5B-Instruct · ~0.5 GB · not inside the APK. Download on Wi‑Fi only (default). Used only when offline / no internet, after small-talk rules; never replaces Groq/Gemini when online. Phone actions stay on the rule engine (this model has no tool calling in v1).

Roman Urdu & English work better than heavy Nastaliq Urdu script on this small model. Low-RAM phones may fail to load (~1.3 GB peak reported for this build).

Image provider

Buttons in Create → Image Studio switch on only when the chosen provider can really do them. “Enhance” is an AI clean-up/re-render, not a true resolution upscaler. Editing needs internet and may be billed by your provider. Keys stay on this device.

Create / Video

Video generation only works with a real video API you provide (base URL + key, stored on this device only). Without one, the Generate button in Create → Video Studio stays disabled — nothing is simulated.
