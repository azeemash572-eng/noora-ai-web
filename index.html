AI model

Primary: Groq (Qwen 27B), Backup: Gemini

groq.com پر مفت اکاؤنٹ بنا کر API key یہاں ڈالیں

With a Groq key NOORA answers with Groq first. If Groq is busy, rejects the key, times out (~20 s) or replies empty, the same message is re-sent automatically to your Gemini key below, and if that also fails, to free Pollinations. A small line under the reply says when this happened. Photos go to Gemini first when a Gemini key is set. No Groq key = everything works exactly as before.

Presets map to real models for the provider you choose.

When set, AI/TTS/image calls go through your Node proxy (env keys). Leave empty to use keys stored on this device.

Personality

Custom assistants

Voice

Uses your phone's speech engine (Google). Urdu → ur-PK, Roman Urdu → Indian-English voice, Hindi → hi-IN, Punjabi → pa-IN. Voice packs are free and then work without internet.

Paid xAI API (api.x.ai/v1/tts). English/Hindi are officially listed; Urdu uses auto-detect. Falls back to the phone voice if offline or on any error.

Keys are saved in local Settings only — never baked into the app.

Wake word / lock-screen listening is not possible in an iPhone web app.

Online / Offline mode

Offline: phone actions (call, message, alarms, timers, reminders, torch, apps, media, settings) run on the built-in rule engine, speech recognition prefers the on-device model, replies use the phone voice. Open questions need Online — or the optional on-device model below.

On-device AI (optional)

Checking…

Qwen2.5-0.5B-Instruct · ~0.5 GB · not inside the APK. Download on Wi‑Fi only (default). Used only when offline / no internet, after small-talk rules; never replaces Groq/Gemini when online. Phone actions stay on the rule engine (this model has no tool calling in v1).

Roman Urdu & English work better than heavy Nastaliq Urdu script on this small model. Low-RAM phones may fail to load (~1.3 GB peak reported for this build).

Owner voice (optional)

Checking…

On-device speaker check (sherpa-onnx + CAM++ model, ~28 MB, downloaded once over HTTPS — not inside the APK). Your voiceprint stays in the app's private storage on this phone and is never uploaded. Not security-grade: a recording or a similar voice can fool it. It never protects typed messages.
